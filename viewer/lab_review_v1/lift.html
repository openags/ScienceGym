实际文件核对

底板与平台安装候选

三个装置参考模型已换入原尺寸 L200/M。安装视图来自白色装置的实际网格，显示底板、覆膜、升降台、上平台和 12 件紧固件；热组件、反射器和外围框架在此视图隐藏，完整模型仍在实验室中查看。

6 mm 亚克力底板采用直通孔和下方大垫圈，上方 5 mm 铝平台采用沉头螺钉。源板的四个 M3 孔位为 X ±37.4904 / Y ±12.4968 mm。两台未装配升降台、24 件紧固件和平台原料已单独列为初始库存。

顶部螺钉需要在热组件覆盖前接近；底部螺钉需要底面可达的受支撑装配姿态。当前静态安装几何不证明螺纹受力、预紧、亚克力应力、承载或机器人装配成功。

    来源与复现

    源文件、官方照片参考与生成的 GLB 在本机缓存，仓库保留下载地址、固定哈希与转换脚本。黑色板件和连杆参考官方照片；材质参数为展示设定。新克隆需要先运行以下命令。

    python assets/thorlabs_l200_v1/fetch_sources.py
python assets/thorlabs_l200_v1/build.py
python assets/thorlabs_l200_v1/check.py
python assets/cooling_lab_v1/build_apparatus_stock.py
python assets/cooling_lab_v1/check_apparatus_mounting.py

    包含厂家几何的完整装置与安装视图同样在本机生成；厂家 CAD 未取得开放再分发许可。普通紧固件由公开尺寸表重建，螺纹采用名义包络，未建螺旋牙型。
