# Originality and attribution

Original geometry, authored metadata, interface examples, package code and review reports are licensed under Apache-2.0. The source paper is cited for scientific facts and object/instrument roles only:

Wang et al. (2023), Mid-infrared single-pixel imaging at the single-photon level, Nature Communications 14, 1073. DOI: https://doi.org/10.1038/s41467-023-36815-3

Accepted paper/SI reading record: final main 9 pages, written SI 12 pages, media description 1 page; two movies decoded and sampled. Raw experimental data and author-modified code were not available. No source figure, photograph, movie, trace, code, CAD, weights or paper PDF is distributed in this package.

Original copper aperture glyphs, the silicon star mark, equipment shells, labels and nominal layout were authored independently. No manufacturer CAD or engineering compatibility is implied. The reported silicon thickness is factual metadata used as a nominal illustrative dimension, not a qualified drawing.

Shared naming/utilities from earlier original ScienceGym asset packages informed this package. No third-party geometry was imported. Blender built-in Bfont produces editable native labels and converted GLB glyph meshes; see Blender-font-notice.txt. No standalone font file is distributed.
