# Thermal meta-device assets: public acceptance review

Accepted as **original static paper-level design assets** paired with `thermalmeta_operations_v2`, for [DOI 10.1038/s41467-024-49630-1](https://doi.org/10.1038/s41467-024-49630-1).

The package contains a compressed, editable Blender scene, a portable GLB, three genuine 1600 × 1100 Cycles CPU previews, guarded static metadata controls and source-attributed manifests. It maps exactly 20 stages, 10 asset groups, 25 anchors and 24 source-review branches. Six condition views preserve three synthetic specimen identities across X/Y; they do not establish six independent specimens.
