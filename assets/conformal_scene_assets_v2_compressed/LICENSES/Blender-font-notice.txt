Blender built-in Bfont provenance

This package was generated using Blender 4.3.2's built-in Bfont for editable labels. GLB labels are converted glyph meshes. No standalone TTF, OTF, WOFF or other font file is distributed.

The upstream Bfont history identifies DejaVu-Lite, derived from DejaVu. The relevant provenance is Bitstream Vera glyphs (2003 Bitstream, Inc.), Arev glyphs (2006 Tavmjong Bah), and DejaVu changes in the public domain. This notice concerns Bfont; it does not claim that Blender's separate international UI font stack was embedded.
