# ScienceGym acoustic scattering: original static scene

DOI: https://doi.org/10.1038/s41467-022-34207-7

This is an independently authored, editable visual asset pack paired with a guarded semantic task. It represents eleven asset families from the accepted complete-source review. It is a static review scene, not acoustic physics, a robot controller, a manufacturing model, an experiment, or a scientific reproduction. All physical actuation is disabled.

## Intended use
- Inspect the Blender scene and portable GLB, original meshes, named anchors and typed evidence boundaries
- Review the three distinct groove-design family illustrations M1, M2 and M3, each protected by its own supported carrier
- Exercise guarded, synthetic state transitions in the paired task package
- Keep experimental branches B01–B05 separate from numerical source-review branches A01–A04

## Qualification holds
All poses, grasps, collision clearances, robot geometry, equipment layout and service interfaces are illustrative and unqualified. Runtime specimen and carrier IDs remain unbound. The first design's source-reported envelope is explicitly distinguished from illustrative M2/M3 envelopes and every authored detail. Groove profiles are intentionally non-source-exact. Carrier occupancy in the scene is an illustrative state, not an actual specimen count, custody receipt or physical replicate. No source parameter tables were converted to CAD.

Closed fabrication, acoustic, optical and motion services contain no exposed electrical endpoint, drive recipe, pressure field, live beam or powered trajectory. The pendulum is shown supported with a retained lease. A closed enclosure, disabled UI or visual indicator does not establish actual safe state. Independent observed safe-state and support receipts remain mandatory in the paired task.

## Originality and provenance
The scene, meshes, materials, lighting, label layout, robot and images were procedurally authored here from primitives. No publisher figure, photograph, CAD, raw data, video frame, author software or acoustic solver is included. Labels summarize the accepted review and source identity; equipment is abstract rather than vendor-exact. The source was published under CC BY 4.0; this new illustrative pack is not author-endorsed.

## Files
- scattering_review_scene.blend: editable scene saved with Blender native compression
- scattering_review_scene.glb: static portable mesh/material/anchor export
- preview_01_overview.png, preview_02_preparation.png, preview_03_metrology.png: genuine Blender Cycles CPU renders
- scene_manifest.json: object and anchor inventory, dimensions, nonexecution flags and render settings
- asset_binding_contract.json: shared exact operation/asset/anchor semantics
- scene_guards.py and test_scene_guards.py: fail-closed semantic adapter and negative tests, with no hardware endpoints
- build_scene.py: original deterministic procedural construction
- paired_task_core_reference.json: reciprocal reference to the stable task semantic core; final archive hashes are recorded outside both archives to avoid circular hashes
- blender_validation.json, guard_test_results.json, independent_review.json and render_receipt.json: verification evidence
- EXPORT_ALLOWLIST.json and DELIVERABLE_MANIFEST.json: verified sanitized archive inventory
- verify_pair.py: checks the scene core and supplied paired task core against reciprocal digests

## Rebuild
Run Blender in background with build_scene.py, then run sanitize_metadata.py and verify_scene.py in Blender plus test_scene_guards.py in Python. Build outputs are native-compressed from the first save. Sanitization removes nonvisual path fields from the compressed Blender stream and PNG metadata, preserving decoded RGBA pixels and geometry. No denoiser was available, so previews use 48 CPU samples directly.

No actual acoustic, optical, motion, fabrication or other hardware was operated.
