# Public export boundary

This export contains authored task contracts, documentation, independent source-audit findings/locators and static tests. It excludes cached publisher HTML, main/SI PDFs, figure/page pixels, full source text, original measurements, CAD, hidden runtime fixtures and the local authoring/export scripts. No remote publication or repository license change was performed by this task.

## Provenance and portability

The source version is identified by publisher URL, exact HTML/SI locator and SHA-256. Host-specific source paths and redirect state are removed. Source bytes were verified in the local authoring review but are not bundled; metadata verification is distinct from fresh byte verification. The main PDF previously reached an identity barrier and was never retried. Complete recovered publisher HTML plus primary SI were used instead.

Run the portable static suite with `python tests/test_prismatic_contract.py`. Optional source-byte rechecking uses `python tests/test_prismatic_contract.py --source-dir PATH_TO_LAWFULLY_OBTAINED_SOURCES`; expected basenames/hashes are in the audit metadata. Missing publisher sources in the default public checkout are a declared skip, not evidence of a failed scientific task. Never fetch around a denied source-access route.

## Claim limits

The task family has seven practical source families, 12 selections and 49 operation templates. Missing dimensions, material recipes, actuation paths, physical settings, specimen counts and episode inputs remain missing. Source conflicts remain explicit. Tests check schema/causal/data contracts using static metadata and synthetic records, not material physics, robot feasibility, physical safety or scientific reproduction. Actor/evaluator release is specified but its runtime loader is not implemented.
