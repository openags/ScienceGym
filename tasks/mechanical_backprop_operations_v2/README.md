# Mechanical backpropagation task-design package

Start with `TASK_DESIGN.md`. Nine physical routes plus a whole-paper campaign use reusable mobile-robot, station-device and analysis-service operations. Read `nonmanual_scope.json` before interpreting the numerical training/retraining material.

This is original design/reference work, not an executable robot environment or experimental replication. Physical spring constants are not self-updating. Missing qualified inputs remain explicit gates.

Run `python tests/test_contract.py` for finite static/symbolic contract checks. These do not run a robot, mechanics solver, printer or experiment. See `VERIFICATION.json` and independent review for the checked scope.

Publish only the curated `RELEASE_BOUNDARY.json` allowlist. Preserve the repository LICENSE. No publisher source text, images, movies, raw workbook or downloaded code is part of that export.
