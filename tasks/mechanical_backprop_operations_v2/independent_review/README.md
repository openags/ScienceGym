# Independent design review

**Pass for a source-bounded whole-paper mobile-robot task-design draft.** No blocking design findings remain. This does not validate a robot controller, physical feasibility, equipment safety, experiment, numerical training run or scientific reproduction.

The package contains nine physical configurations plus a campaign dispatcher, 46 operation templates, nine typed physical routes, ten transfer contracts and 18 unresolved qualified-input gates. I independently reran all 43 author tests, checked 37 additional static properties and verified the two repaired symbolic false-accept cases. These are finite design checks only.

## Repairs verified

- Iris load-free imaging now precedes physical weight transfer
- Concrete fabrication/postprocessing/inspection/assembly/test/archive transfers preserve carrier, object identity, zero-load state and custody; digital processing does not teleport the sample
- Gradient repeats contain both separate load phases and pairing; regression analysis sits outside the seven-load acquisition loop
- Actor-facing behavior identifiers are neutral and classification labels stay evaluator-only
- Supplied or initial geometry no longer requires a fictitious numerical training history
- Complete source-matched campaign status requires every physical configuration, all regression loads and three independent trials per case; subsets remain partial
- The symbolic gradient checker rejects missing final pairing and unknown phase vocabulary

## Scope and remaining limits

The scientific boundary is preserved: fabricated lattices support physical field and final-response tests; training updates, task switching and damage retraining are computational. The package does not make existing printed specimens change because their digital geometry changes. Source repeat counts are not invented specimen counts. Fabrication, postprocessing, mounting, camera/force calibration, load placement, unloading/recovery, transport and cleanup are explicit authored robot responsibilities with device-service boundaries.

I checked the main empirical and Methods sections, supplementary experimental/implementation text, movie descriptions and reporting-summary text. Four retained source files matched their declared hashes. This was not an exhaustive theory/figure audit or independent numerical reproduction of the source workbook. Movies remain unviewed; complete code, historical raw-image/specimen lineage, exact manufacturing geometry and Iris load mapping remain unresolved. Their absence is retained as source limits and execution gates.

The actor/evaluator separation is a projection contract, not an implemented security boundary. Actual robot reachability, grasping, material handling, qualified process cards, calibration, force-scale conventions and safe station execution still require validation. Source outcomes cannot replace new observations or become forced pass thresholds.

Only the authored allowlisted deliverables are public-eligible. Source PDFs/text/pixels, movie frames, raw workbook data and copied code remain private and excluded. See `audit.json` for review checks, resolved findings and hashes of the substantive reviewed files.
