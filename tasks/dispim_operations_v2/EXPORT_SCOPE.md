# Public task-design scope

This is a newly authored paper-grounded task specification, not a runnable environment, scene bundle, controller, laboratory protocol deployment or scientific reproduction. ScienceGym specifies the task design and the requirements for supporting scenes and assets; runtime scene and asset bindings remain to be implemented and validated.

The authored project is covered by the repository's existing Apache-2.0 LICENSE. Cited publications, omitted source media, data, third-party code and supporting assets retain their respective terms. This export does not relicense them or claim their redistribution clearance.

No publication PDFs, extracted full text, source images, video, datasets, manufacturer CAD, asset binaries or credentials are included. Mentions of existing assets or past source inspections describe the authoring archive, not bundled or validated runtime dependencies. Local filesystem roots have been replaced by source-archive:/// locators; these intentionally do not resolve or trigger retrieval.

Historical source SHA-256 values pin cited source bytes. They are not checksums of this transformed public copy. The following superseded/local check files are intentionally omitted: AUTHORED_MANIFEST.json, VALIDATION.json. No old check report constitutes a present execution or availability pass.

Review TASK_DESIGN.md together with RELEASE_BOUNDARY.json. All files except the explicitly selected actor projection and matching public cards are author/evaluator references. A loader and evaluator have not been implemented. Unknown inputs remain unknown and must block dependent stages instead of being filled by guesses.

The original authoring directory was preserved. No experiments, physics, robot trials or remote publication were performed by this export preparation.

## English field names

Language-tagged narrative keys use the `_en` suffix in this English edition, replacing their historical `_zh` names. Task and evidence identifiers, numeric values and substantive meanings are unchanged. Consumers of the historical draft schema must update these descriptive-key references.
