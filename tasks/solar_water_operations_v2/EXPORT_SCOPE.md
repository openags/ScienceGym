# Export boundary

Public-eligible subject to final independent review: exactly the files listed in EXPORT_ALLOWLIST.json, containing original task commentary, metadata, bounded design contracts and offline Python checks.

Not included: source PDFs, extracted source text, screenshots, figure/video assets, acquisition traces, laboratory reports, publisher data, credentials, private research paths or unreviewed files. A recursive directory copy is not an authorized export method. Symlinks and unknown paths fail verification. The manifest records each payload digest and byte count; its own digest is intentionally outside the payload.

The export remains a bounded nonbiological design, never full-paper physical completion. Source access completeness is not execution completeness. Biological operational content, open hazardous fabrication and pollutant preparation are excluded. The author performed no public write and no scientific or physical execution.
