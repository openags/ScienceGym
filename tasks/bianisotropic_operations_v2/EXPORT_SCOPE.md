# Export scope and visibility

Export only the exact files listed in `EXPORT_ALLOWLIST.json`. Its `files` records provide byte counts and SHA-256 hashes for every payload file; the manifest lists itself but does not recursively hash itself. Verify the allowlist before transferring the task into a release checkout.

This payload contains independently authored English task, station, custody, input and evaluator contracts; concise source attribution/locators; source-access facts and hashes; factual dimension/outcome transcriptions; and standard-library static/synthetic tests. It is a reviewable design, not a supported runtime task command.

Do not export the main/SI PDFs, extracted full text, page renders, download headers, original raw recordings, unsupported CAD, author code/models, build scratch scripts, local paths, credentials or caches. Optional source-byte tests use a reviewer-provided private directory and never retrieve or bundle those files.

The paper's main article explicitly carries CC BY 4.0 on page 9. The official SI has no separate license statement in the inspected supplement. No paper figure, screenshot or source-text dump is redistributed here; additional media reuse would need its own rights/credit-line review. Original task prose does not imply author endorsement or relicense future third-party assets.

Public repository visibility is different from actor visibility. `RELEASE_BOUNDARY.json` defines an allowlist projection for the future actor; source outcomes, rounded coefficients, reference routes and evaluator/fault information remain author/evaluator-only. The static projection tests do not constitute a production runtime loader or sandbox boundary.

Permitted readiness claim: source-grounded whole-paper task-design draft with named static and synthetic bookkeeping checks. Prohibited claims: completed physical or numerical experiments, validated robot scene, scientific reproduction, exact author CAD, accessible original raw data, physical 70/80-degree or GSL panels, a reported physical four-microphone retrieval experiment, or publication already performed.

No public repository writes, uploads, deployments or source publication were performed while constructing this package. Maintainer review and publication are separate actions.
