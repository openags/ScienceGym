# Exact export boundary

Only files explicitly named in EXPORT_ALLOWLIST.json may be copied. Every payload except that manifest is hashed; wildcards, path traversal, symlinks, missing and extra files fail. Publisher PDFs, parser dumps, SI images, video/data bytes, downloads and their derivatives are excluded. Original factual metadata and source hashes identify evidence without redistributing source bytes.

Only agent_visible.json is actor-visible. Other artifacts are for author/evaluator review. This local work performs no public write; parent publication is a separate action. Preserve all source-access, unresolved-input and execution-limit labels in downstream views.
