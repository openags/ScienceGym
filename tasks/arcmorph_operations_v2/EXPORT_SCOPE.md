# Export boundary

Only the exact bounded UTF-8 text inventory in tests/verify_export.py is permitted. EXPORT_ALLOWLIST.json binds byte counts and SHA-256 digests. The exporter rejects extra/missing names, noncanonical paths, symlinks, special entries, duplicate ZIP names, encryption, binary content, private local paths and mutated bytes. Source PDFs, figures, photographs, notebooks, raw archives and scene binaries are excluded. The original scene package is separately reviewed and distributed.

This artifact is reviewer/evaluator material; agent_visible.json alone is the documented actor allowlist. A label is not operating-system access isolation. Re-export after any change requires repeating review and verification and regenerating the manifest.
