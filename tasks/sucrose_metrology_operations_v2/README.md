# Sucrose speckle metrology: bounded task design

Seven original nonbiological branches and an offline synthetic contract for DOI 10.1038/s41467-026-72281-3. Start with TASK_DESIGN.md and asset_binding_plan.json.

Run `python -m unittest discover -s tests -v`, `python tests/verify_package.py` and `python tests/verify_export.py`. Only agent_visible.json may be supplied as actor context.

This package does not implement physical equipment, optical physics, PCA analysis, fabrication or a whole-paper replication. Default flow is unresolved and held. Any mock clearance is fixture-only. Source text and pixels remain outside this package.
