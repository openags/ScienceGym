# Aqueous sucrose speckle metrology

## Bounded outcome
This is an original task and record-contract design grounded in the nonbiological parts of Perrella and colleagues, Nature Communications, DOI 10.1038/s41467-026-72281-3. Seven branches cover aqueous preparation, fresh reference readings, calibration, interpolation, same-sample repeatability, drift/dark records and a safe conflict hold. Three configured station profiles distinguish SPP2/1064 nm, SPP5/1064 nm and SPP5/532 nm. A new profile is a new session. Certification is a required input; none is supplied or inferred.

All fabrication, SEM work and open optics are closed supplier-qualified services. Prebuilt input permits describing the bounded measurement subset but never counts as completing fabrication. No biological branch, real actuator, optical simulation, CAD replica, raw scientific data or implemented PCA is included. “Complete” can mean a reviewed static design or a valid synthetic trace only. This is not whole-paper completion.

## Physical work and custody
Preparation verifies materials and a qualified recipe, records tare and transferred masses, mixes to a separately qualified endpoint, labels/caps the bottle and filters an identified aliquot into an identified tube. The stock bottle, receiving tube and optical cartridge are different custody objects. A fresh reference reading is required for each aliquot at the beginning of the current episode; a stored bottle reading is insufficient. Reference cleaning and carryover checks are qualified-card requirements, not invented wash instructions.

The chip remains retained and docked across calibration and dependent measurements. Before each sample switch, a clamp command must be followed by an independent clamp-state observation. Only then can inlet transfer be requested. A closed qualified exchange service returns its own completion, carryover and stable-flow receipt before a separate bubble observation and acquisition. A command acknowledgement never substitutes for these observations. Unknown bubbles, stale references, drift alarms, identity mismatches or failed receipts cause a hold. The old attempt remains archived.

At the end, the service isolates the fluidics, verifies the enclosure safe for exchange, invalidates calibration, retrieves/inspects the cartridge, archives records and closes cleaning/storage custody. The source does not supply robot grasps, connector forces, flush volume, cleaning chemistry, docking coordinates or authenticated service APIs. These remain required unresolved inputs.

## Flow conflict
The source gives 2 cc/min in Methods and approximately 50 microlitre/min in the figure caption, a forty-fold discrepancy. Neither is chosen, averaged or used as an executable setting. The default example is a safe-held episode without any pump action. A separate measurement fixture uses an explicitly authored logical service-clearance card only to exercise the contract. It does not resolve the source discrepancy, authorize hardware, establish pressure safety or supply a flow rate. Production authority is always false.

## Scientific interpretation
Fresh reference RI, wavelength, setup/mount version, plate identity, aliquot and image pair are all bound to one run. Calibration fitting and preprocessing must be frozen using only declared calibration records before held-out records are evaluated. An unknown query must remain inside the calibrated domain. Beam-profile and speckle channels are not interchangeable. The dark-frame branch preserves a distinct dark channel rather than pretending that it is a valid sample speckle image.

Within-sample SD describes repeatability. Independent calibration runs, technical repeats and SEM across precision estimates stay distinct. The main eight-sample plan and four plotted/reporting tests are retained as a source wording conflict. The reduced fixture is three standards, two test identities and three technical repeats for schema exercise; it does not pretend to reproduce the source sample counts.

Reference accuracy, repeatability, wavelength-dependent systematic bias and temperature drift are separate concepts. The SI estimates wavelength bias as large as about 0.63 percent and cannot provide complete intermediate-concentration correction. No source precision is an absolute-accuracy result or pass threshold. Temperature ranges and exposure durations reported in the paper are observations, not automatically valid service tolerances. SPP labels, inconsistent precision SEM wording and grid arithmetic remain visible. No simulation is made from the unresolved grid specification.
