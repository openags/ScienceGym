# Local review and export boundary

Only the exact original Markdown, JSON and Python files in EXPORT_ALLOWLIST.json belong to this review candidate. This is a local package, not a published repository change. No remote write or license change was performed.

The source chain is cited in provenance.json and source_access_audit.json. The inspected main reprint and official SI stay outside the package. Full extracts, author-site cached pages, source plots, screenshots and PDFs are excluded. Source SHA256 values identify audited evidence; they do not grant republication rights. The earlier arXiv nonexclusive distribution license is not a blanket reuse license.

Original source summaries and task contracts do not license the underlying paper, figures, third-party geometry or future hardware assets. Future contributors must obtain a suitable license or make original assets. No publisher pixels or third-party CAD are supplied.

The package is source-complete for task-design review and explicitly incomplete for exact fabrication, raw-data reanalysis, physical execution or numerical reproduction. The executable checks operate on static JSON and artificial test records only. Public release, repository integration and scientific execution are separate decisions.

All documents except agent_visible.json are authoring/evaluator material. An actor integration must fail closed and instantiate separately reviewed runtime cards and current observations. It must not recursively expose this directory.
