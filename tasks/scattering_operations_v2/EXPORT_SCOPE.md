# Export boundary

Only files explicitly inventoried in EXPORT_ALLOWLIST.json are exported. The manifest records exact relative paths, byte sizes and SHA-256 hashes. The archive contains original authored design text, original synthetic Python bookkeeping checks and review results. It excludes publisher PDFs, supplementary files, rendered source pages, video frames, publisher/author scientific source code, raw scientific data, credentials, caches, local transcripts and internal paths. Task and scene are separate exact archives pinned by a pair receipt. Hashes establish byte identity only.
