# Export scope

Only files named and hashed in EXPORT_ALLOWLIST.json may be copied. The manifest itself is the sole unhashed file to avoid a circular digest. Reject extra files, symlinks, path traversal, source PDFs, pixels, raw source text, test caches and private inputs. Original task design and synthetic tests may be publicly reviewed; only agent_visible.json is the actor-facing contract. Source outcomes and evaluator files are never actor inputs. This local work performs no external publication.

Task contracts and synthetic controls are original additions; paper observations remain attributed, unresolved ambiguities remain explicit, and no source pixels/prose are reproduced.
