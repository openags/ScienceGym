# Export scope

Only exact paths in `EXPORT_ALLOWLIST.json` are candidates for parent review and publication. The allowlist includes itself but deliberately has no self-hash; every other payload file is byte-counted and SHA-256 hashed. A verifier rejects missing, changed, extra or symbolic-link files. Regenerate the manifest only after reviewed edits, never to bless an unexplained mismatch.

The task text, records and tests are newly authored. The underlying article is explicitly CC BY 4.0, with credit-line exceptions. Its attribution and source URLs are in `provenance.json`; the official supplement remains private. No publisher PDF, full-text dump, screenshot, photograph, figure image or raw dataset is included. Tool-response hashes identify receipts, not original publisher bytes. No source-access denial was retried or bypassed.

This export contains no credentials, runtime paths, robot binding, physical simulation, generated scientific data, live instrument controls or executable numerical model. The repository’s existing license must not be represented as relicensing source materials. Parent review/publication is separate; this work has made no external write.

Public files are inspectable by contributors, but future benchmark actors must receive only the allowlisted goal/material/input/observation projection. A repository file’s visibility label is not an implemented security boundary.
