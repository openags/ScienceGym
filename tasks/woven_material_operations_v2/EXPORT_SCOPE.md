# Original export scope

Only original UTF-8 task metadata, prose and Python validators/tests are allowed. Source papers, text extracts, figures, pixels, videos, author CAD/code, workbooks, logs and caches are excluded. Source provenance contains bibliographic metadata, URLs, hashes, locations and factual descriptions only.

agent_visible.json is the sole actor projection. Every other file is evaluator/auditor-only. Deterministic public fixtures are integrity test vectors, not production authentication. Inventory/member/envelope checks establish exact export integrity, not an external trust signature. Scene geometry is separately packaged; physical/numerical reproduction, instrument recipes, real adapters and robot qualification are absent.
