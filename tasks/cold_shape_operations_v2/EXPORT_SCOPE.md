# Export boundary

Export only original authored files named in EXPORT_ALLOWLIST.json. Publisher XML/PDF/image/movie/workbook bytes and extracted text stay outside this package. Source identity, concise paraphrases, locators, verified URLs and hashes are permitted provenance references, not redistributions of the paper.

The paper states CC BY 4.0 with third-party-material caveats. The supplement has no separate license notice in the inspected file. A provisional patent disclosure is present; this package makes no patent or commercialization-rights claim. ScienceGym work is independent and does not imply author endorsement.

No external publication or repository write is authorized by the presence of this local export boundary. No machine-readable operation is a real hardware command. Software tests must not be described as physical experiments.
