# Deconwolf：从制备到成像收尾的整篇任务设计

## 这次交付是什么

把冻结集合中**已有的 Deconwolf 原始论文**转成一套整篇任务家族，不增加“新读论文”计数。覆盖六条实体制备/成像分支，以及论文从已有图像开始的七条数据比较分支。不是仅让机器人搬一张已经完成的玻片，也不是把所有样品都当成同一个实验连续处理。

**已经完成：任务设计与结构化规格。尚未交付：可运行环境、预设显微图像像素、真实实验或物理仿真。** 科学输出目前是带条件的语义合同。以后可以接预设图像，不必先开发光学/生物过程模型。

详细参数、原文定位和英文技术规格见 [TASK_DESIGN.md](TASK_DESIGN.md)。本文件是阅读入口，不是真实实验室 SOP。

## 六条实际动作链

所有链都包含：读标签、找材料、打开容器、选正确试剂、装新吸头、移液/换液、记录样品身份、盖好容器、装入运输托盘、移动到下一工位。等待通过虚拟计时器表达，化学/生物结果不作物理计算。

### 1. U-2 OS / tubulin

选 **18 mm 圆盖玻片**和细胞来源 → 放入培养容器并接种 → 培养 → 固定 → 透化 → 封闭 → 一抗 → 逐次洗涤 → 再封闭 → AF555 二抗及 DAPI → 逐次洗涤 → Prolong Gold 装片 → 盖好托盘并运到 Zeiss 共聚焦代理工位 → 装片、找视野、调焦、设参数、采集 → 卸下并转运至 Ti-E / iXon / 100× 工位 → 找回**同一样品、同一视野**并采集 → 保存原始数据及比较记录 → 卸片归档、清理

关键控制：**共聚焦先于宽场**；圆盖玻片不能换成 HAP1 的方盖玻片；不同模态各自保留采样参数。

### 2. HAP1 / chr16 iFISH

选 **22×22 mm 方盖玻片和六孔板** → 接种、培养到原文描述的状态 → 固定 → 淬灭 → 三次洗涤 → 透化 → 三次洗涤 → 原文酸处理 → 两次洗涤、SSC 漂洗 → 选择立即继续或原文允许的保存分支 → 杂交前平衡 → 预杂交 → 选正确探针批次并配任务混合物 → 换入主杂交液、Fixogum 封闭 → 加热处理 → 主杂交 → 漂洗及逐次温洗 → 第二次荧光寡核苷酸杂交 → 洗涤、Hoechst 染色、终洗 → 装片 → 运至 Ti-E / iXon / 100× → 找视野、调焦、分通道采集 → 保留 raw/DW 对应及细胞核身份 → 卸片归档、清理

关键控制：培养板是制备用容器，不把整块六孔板当作原文成像载体；边界比较里的 **51 层 HAP1 图像**不是所有 iFISH 采集的通用设置。

### 3. SKBR3 / GAPDH smFISH

细胞来源、培养基及任务载体 → 培养 → 执行**明确标为基准设计补充的上游准备卡**，衔接原文未说明的固定/透化 → 选 GAPDH 探针 → 配液与主杂交 → 洗涤 → 荧光二级寡核苷酸杂交 → 洗涤、Hoechst 染色 → 原文标识的封片液任务道具 → 装片并运至 Ti-E / Zyla / 100× → 找视野、调焦、设置 z-stack 并采集 → 分别查看 Intensity 与 DoG 的 raw/DW 对照 → 卸片归档、清理

关键控制：不能借用 iXon；Intensity 与 DoG 是两个比较条件，不能以“点更多”统一判定更好。原文未给出的制备细节没有伪装成原文事实。

### 4. MKI67 / 冷冻 TMA

从原文购买的 **5 µm 冷冻组织切片**入口开始 → 固定 → 两次 PBS 漂洗 → 两次冰冷乙醇漂洗及孵育 → 换液复水 → 探针/杂交操作 → 洗涤、染色及装片 → 运至 20× 空气物镜工位 → 逐个定位并采集十个任务视野 → 换到 60× 油镜配置并找回指定子集 → 保存匹配记录 → 查看 DoG、CNR、阈值与高质量点对照 → 卸片归档、清理

关键控制：原文一方面称 MKI67 直接荧光标记，另一方面说继承 SKBR3 杂交后步骤。因此任务提供**直接标记解释**与**字面继承解释**两种有标签的分支，不声称已解决歧义。十个采集视野与图中五个分析视野不混为同一计数。

### 5. GFAP / FFPE 脑组织 TMA

从 FFPE TMA 块开始 → 在切片代理设备设定厚度并切片 → 烘片 → 执行原文未展开细节的脱蜡任务卡 → 抗原修复代理工位 → 配 TNB/一抗并孵育 → AF555 二抗及 DAPI → Fluoromount-G 装片 → 运输、装载 → 用 Zyla / 60× 与 Leica / 63× 分别定位同一 ROI 的 **4×4 拼图、10% 重叠** → 独立完成图注支持的 100× 比较分支 → 保存 raw/DW/DL2、轴向及低强度差异 → 卸片归档、清理

关键控制：不能把 60× 的相机、层数直接复制给 100×；原文没有要求 GFAP 必须共聚焦先拍，不套用 tubulin 的先后规则。

### 6. Nup153 / 核孔

先读取原文物种/染料冲突卡 → 以明确标签创建任务样品 → 执行原文未给出的上游准备任务卡 → 选择原文 Nup153 一抗与二抗并完成任务处理 → 通过基准设计补充卡装片 → 运至**独立 Leica STED 代理工位** → 设原文支持的光路及采集条件 → STED 采集 → 随后共聚焦采集 → 查看相应模态的 PSF 与 raw/Huygens/DW 比较 → 卸片归档、清理

关键控制：原文“human PtK2”及二抗/Oregon Green 表述有冲突，必须保留。预设画面不证明染料与波长在真实实验中兼容。此分支不冒充一套完整可信的现实配方。

## Agent 的初态与目标

- 初态：在收货区，工具为空；细胞/组织来源、试剂、探针批次与空载体分别有标签；显微镜未装样、未调焦、未采集。必要上游资源以原文真正的入口提供，例如购买的冷冻切片、引用既有方法制成的探针批次
- 操作：移动底盘到工位、抓取/放置、开盖/关盖、移液/换液、混合、计时、装片/夹紧、设置光学控制、依据预览调焦定位、采集保存、卸片清理
- 目标：完成对应制备与成像分支，保存可追溯的原始和比较记录，归档样品并恢复工位安全空闲状态。整篇长任务需要完成所有实体及数据分支，不以 tubulin 一条代替整篇
- Agent 可读 `initialstate.json`、`agentgoal.json` 和原文参数/未知卡；独立 `evaluator_reference.json` 不给 Agent

## 怎么验收

验收读取可信环境事件，不读取 Agent 自己写的 passed=true。需验证每次材料转移、洗涤计次、计时、载体身份、显微镜配置、视野配对和原始数据父子关系。raw 不可改写；后处理结果必须有真实的任务采集/导入记录作父项。

名义输出只在准备状态、装载、焦点、视野和参数都满足时出现。错误通道、离焦、过曝、错视野、气泡分别产生不同的**基准预设**反馈。错误试剂造成的失败样品不能靠改名恢复；需要保留失败记录并从新样品身份重新开始。

收尾要求：样品有归档位置，台面无待卸样品，采集停止、快门关闭、物镜回到装卸/停放状态，试剂封闭，废液/吸头有去向，工具归位。

## 原文未知、资产替代与交付边界

- 来源参数能查到的逐项绑定；查不到的保留 unknown。任务用明确标签的补充操作衔接，**不是把未报告的体积、时间、培养条件编成论文事实**
- 原文可疑的 32 mM catalase、iFISH 浓度单位差异、63/65 loci、Lanczos-3/5 等保持字面与冲突标签，不作为现实 SOP 推荐
- 复用现成详细 Ti-E、iXon、Zyla、盖玻片/六孔板资产；镜头变体、Leica/Zeiss、移液器、底盘等缺失部分有诚实的代理标签，不声称已生产新精细模型
- 七条数据分支包括软件基准、PSF、边界、合成点、ISST、OligoFISSEQ 与 RLN 比较。它们在原论文中从已有/计算图像开始，因此不凭空补写新的湿实验
- `preset_output_contract.json` 现在只有**条件与语义输出**，没有显微图像像素；当前不可称作“可运行仿真”或“已完成实验”

可直接进入下一步：按这套任务规格选择一个分支做交互落地，同时保留整篇其余分支的设计。无需再次退回“只统计、只做更多工具”的阶段。
