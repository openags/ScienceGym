# Export scope

Export only the authored files listed in `EXPORT_ALLOWLIST.json`. The temporary source-inspection directory has been removed. No source PDF, extracted article text, source figure, screenshot, movie, downloaded data archive or CAD asset is included.

The source article is CC BY-NC-ND 4.0. Attribution and factual locators are retained; no rights in publisher assets are granted. Do not replace or modify the destination repository LICENSE. This design has no remote-write or publication action.

The public review package contains reference routes and evaluator contracts. A future runtime must give the actor only the selected projection described by `agent_visible.json`, not the complete public directory. No runtime projection loader, robot controller or scientific engine is implemented.

Validation logs concern structural and synthetic metadata tests. They are not a record of an experiment or robot execution. Missing recipes, device methods, exact masks and historical image/data inputs remain explicit gates.
