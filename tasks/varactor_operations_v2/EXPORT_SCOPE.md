# Export scope

This text-only package exports original task contracts, original offline tests and independent review. EXPORT_ALLOWLIST.json pins every exported member by exact path, byte count and SHA-256. The validator also has an independent hard-coded path allowlist. Unknown members, duplicate ZIP names, noncanonical paths, linked files and altered hashes are rejected.

Only agent_visible.json may enter the actor context. All other files are evaluator/auditor material. No paper/SI pages, source images, data archives, source code, author CAD, credentials, local paths or physical controls are included. Static scene assets are a separately reviewed original package; their IDs are bound here without treating visualization as qualified geometry.
