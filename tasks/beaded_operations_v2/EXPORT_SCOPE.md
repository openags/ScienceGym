# Export scope

Export only files enumerated in `EXPORT_ALLOWLIST.json`. These are authored task-design documents, structured contracts and static checks. Source titles, DOI links, section/figure/page locators and factual material/condition values remain for provenance.

Exclude publisher HTML/PDF/full text, source or rendered figure pixels, movies, raw author datasets, external geometry/code, access-session state, local build scripts and caches. No new license claim is made for publisher material. Keep the destination repository's original LICENSE unchanged.

The export is reviewer-facing. `RELEASE_BOUNDARY.json` defines the smaller actor-facing episode payload. Publishing this design is not permission to leak evaluation routes or outcomes into a benchmark episode.
