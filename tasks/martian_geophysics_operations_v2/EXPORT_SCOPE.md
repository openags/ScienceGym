# Exact export scope

Only files enumerated in EXPORT_ALLOWLIST.json may be exported. That file fixes the exact payload paths and SHA-256 digests; unlisted files, symlinks, traversal paths, unsupported file types and changed payloads fail verification. Publication is owned by the parent task.

The package consists solely of original English design, contracts, synthetic tests and independent review receipts. No publisher PDF, workbook, source extract, screenshot, raw figure data or source script is included. Only agent_visible.json is actor-eligible; all other payloads are author/evaluator material.
