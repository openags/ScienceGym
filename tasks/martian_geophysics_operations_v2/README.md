# Martian mineral-physics task design

Original English task-design conversion of Pierru et al., Nature Geoscience (2026), DOI 10.1038/s41561-026-02104-z. This is a design package for specimen custody, qualified facility-service exchanges and evidence lineage. It is not an executable laboratory protocol, a robot demonstration, a physics simulation or a reproduced experiment.

All 13 source route families are represented. Extreme pressure, heating, laser levitation, gas mixing, X-ray generation, specimen cutting and instrument operation remain closed qualified services. The acting agent may handle released carriers through qualified interfaces and request existing approved service jobs; it cannot provide actuator parameters or authorize service qualification.

The full retained written main article and 33-page supplement were read. Six supplementary tables were inspected, with dense model grids structurally traversed rather than independently recalculated. The original main PDF and main/Extended Data figure pixels remain unavailable after an access hold; no retry was made. Publisher source files, extracts, workbooks and images are excluded from export.

Ten source discrepancies remain unresolved. In particular, the temperature-correction sign and H5897/H5898 temperature assignment cannot be silently repaired. Source observations never act as live measurements or completion targets. Only agent_visible.json is eligible for an acting-agent input.
