# Export boundary

Only exact files enumerated by EXPORT_ALLOWLIST.json are permitted. The allowlist itself is the final additional member. Symlinks, path traversal, duplicate ZIP members, hidden files, additional directories, appended ZIP data, source PDFs/XML/text dumps, source figures/tables/video frames, CAD, author data/code, caches and private paths are prohibited.

These original descriptions, contracts and tests state facts with source locators. Source rights remain CC BY 4.0 and are not relicensed by the host repository. No source artwork is included. Only agent_visible.json is actor-visible.
