# Directional cooling task design

Start with TASK_DESIGN.md. This package covers 11 physical route leaves plus explicitly separated model/concept work. operations.json and dependencies.json define causal operator/device contracts; evidence, controls, lineage, input gates and release limits are separate files.

Run `python tests/test_directional_contract.py` for static and synthetic-record checks. They do not run a robot, a thermal simulation or a scientific experiment.

Original publisher text, figures, SI PDF and data are not bundled. The article was read through the publisher web reader without a local article hash. SI source hashes are documented in source_access_audit.json. No original repository LICENSE is changed.
