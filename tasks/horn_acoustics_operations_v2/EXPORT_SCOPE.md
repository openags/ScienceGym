# Export scope

Only files named in EXPORT_ALLOWLIST.json form this local review candidate. The manifest records exact bytes and SHA-256 for every payload file, omits its own hash, and lists itself. Unexpected files, symlinks, missing files and changed hashes fail export validation.

No publisher PDF, XML, extracted prose, figure pixels, Table 2 data, private source audit, CAD, audio or simulation result is included. Geometry facts are independently represented with source locators. Original text and tests do not relicense the paper or its apparatus.

The full candidate is evaluator-facing. agent_visible.json defines the future actor projection; it does not make the whole folder agent-visible. No public upload, commit, robot run or physical simulation was performed.
