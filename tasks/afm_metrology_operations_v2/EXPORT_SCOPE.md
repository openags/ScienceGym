# Export scope

The exact allowlist contains only original English task descriptions, JSON contracts, synthetic verification code and review receipts. Source hashes and public article URLs identify evidence but do not bundle source bytes. Source-archive locators are nonresolving provenance labels, not paths to a server. Do not recursively copy the surrounding source packet or authoring directory.

The cited article is CC BY 4.0, subject to third-party credit-line exceptions. This package uses original factual paraphrases and source locators; it contains no source figure, pixel, full-text extraction, SI PDF or external MATLAB program. The source license does not relicense omitted assets or establish execution readiness.

The actor-facing allowlist is exactly agent_visible.json. Evaluator source outcomes and synthetic expected observations must remain separate from actor input in any future integration. No production harness or trusted observation authority is implemented.

The exact-file checker rejects unlisted payloads, changed hashes, symlinks, paths outside the package, prohibited media suffixes and machine-root paths. It is not a security scanner or a scientific validator. Publication is a separate authorized action and is not performed here.
