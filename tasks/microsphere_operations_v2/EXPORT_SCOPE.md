# Export boundary

Only original authored files enumerated by EXPORT_ALLOWLIST.json may enter the sanitized archive. The exporter rejects symlinks, traversal, unlisted files, executable binaries, publisher files, private absolute paths, hidden metadata and stale hashes. Python source is original offline validation software; it contains no hardware interface. The archive retains restricted-source rights notices.

Task and scene are separate paired deliverables. Their stable payload digests exclude reciprocal binding files, status, verification, allowlists and manifests to avoid hash cycles. Those exclusions are declared, not concealed. Final package manifests cover bindings too.
